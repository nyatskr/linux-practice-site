## 怎么读这份台账

- `blocked` / `unknown` 不是失效，是「这次没查到」。连续两次都 blocked 才值得人工看一眼。
- `dead` 才是真失效。确认后要人工把该条的 `status` 改成 `dead`，并在 `docs/video-map.md` 记一笔——工具不会自己改。
- 工具不会把 `candidate` 升级成 `verified`：链接活着 ≠ 内容讲对了，验收只认人工。

下次巡检建议在 2026-11 月底，或站点发布前跑一次。
